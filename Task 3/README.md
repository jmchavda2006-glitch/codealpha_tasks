### 📌 Project Overview
The objective of Task 3 was to move beyond UI aesthetics and conduct a deep-dive UX audit. I selected the **Amazon Mobile Shopping App** to analyze its user journey, evaluate institutional strengths, and identify frictional weaknesses.

### 🎯 Objectives Achieved
* Mapped the user journey of an analytical tech enthusiast, from product discovery through checkout.
* Conducted a heuristic evaluation identifying extreme visual cognitive load and subscription-based dark UX patterns.
* Proposed and sketched 3 high-impact UI/UX improvements: 
  1. De-cluttering search results cards.
  2. Introducing interactive, dynamic filters for the community review hub.
  3. Designing an ethical, side-by-side checkout architecture to prevent accidental subscriptions.
