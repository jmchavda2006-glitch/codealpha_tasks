### 📌 Project Overview
This project is part of the CodeAlpha UI/UX Design internship. The objective of Task 1 was to create low-fidelity wireframes for an Education or Campus Management Platform named **Campus Connect**. The focus was entirely on establishing layout, structure, and basic user flows without getting distracted by colors or typography.

### 🎯 Objectives Achieved
* Designed foundational wireframes for key screens: Splash Screen, Dashboard, Course Search, Course Details, and Student Schedule.
* Established intuitive user navigation and information architecture.
* Utilized a grayscale, sketchy aesthetic to emphasize functionality over final visual polish.
